# 现代化仓库管理系统 (Warehouse Management System)

一个基于现代化技术栈（Vue 3 + Spring Boot 3）构建的高性能、易扩展的仓库管理系统。系统实现了从物资入库、库存管理到报表统计的全流程数字化管理，界面美观，交互流畅。

## 🛠 技术栈
- **Frontend**: Vue.js 3 + Vite + Element Plus + Pinia + ECharts
- **Backend**: Java 17 + Spring Boot 3 + Spring Data JPA
- **Database**: MySQL 8.0
- **DevOps**: Docker + Docker Compose

## 🚀 快速启动 (Docker)
只需一行命令即可完整启动整个系统（包含数据库、后端和前端）。

1. **确保 Docker Desktop 已运行**。
2. **在项目根目录打开终端，执行以下命令**：
   ```bash
   docker compose up --build
   ```
   > *注意：首次启动需要下载基础镜像和构建应用，可能需要几分钟时间，请耐心等待直到控制台不再快速滚动日志。*

## � Services

## ✅ Verification - 基本验证方式
为了验证系统是否安装成功并正常运行，请按以下步骤操作：

1. **访问系统**: 打开浏览器访问 [http://localhost:3001](http://localhost:3001)。
2. **登录系统**: 使用管理员账号 (`admin` / `123456`) 进行登录。
3. **查看仪表盘**: 登录成功后，应能看到仪表盘页面，包含库存概览饼图和出入库趋势折线图。
4. **验证数据**: 点击左侧菜单 **"物资管理"**，您应该能看到预置的测试数据（如："高性能笔记本"、"无线鼠标" 等）。
5. **测试功能**: 点击 **"物资入库"** 菜单，尝试添加入库一条新数据，若提示成功并跳转，说明前后端及数据库连接正常。

## 📷 功能介绍
1. **用户管理模块**
   - **用户登录/注册**: 安全的身份认证机制。
   - **权限控制**: 基于角色的访问控制 (RBAC)。

2. **仓库管理模块**
   - **仓库/货架管理**: 灵活定义仓库结构和货架容量。

3. **物资管理模块**
   - **物资信息**: 详细记录物资规格、单价、供应商等。
   - **出入库管理**: 完整的出入库流程记录与追溯。
   - **库存预警**: 实时监控库存水位，低库存自动高亮提醒。

4. **报表统计模块**
   - **可视化报表**: 集成 ECharts 图表，直观展示库存分布和资金占用。

5. **系统设置模块**
   - **基础数据**: 统一管理物资分类、单位、供应商等基础信息。
